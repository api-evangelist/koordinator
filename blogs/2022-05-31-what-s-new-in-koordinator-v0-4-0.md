We are happy to announce the release of Koordinator v0.4.0. Koordinator v0.4.0 brings in some notable changes that are most wanted by the community while continuing to expand on experimental features. And in this version, we started to gradually enhance the capabilities of the scheduler. Install or Upgrade to Koordinator v0.4.0 ​ Install with helms ​ Koordinator can be simply installed by helm v3.5+, which is a simple command-line tool, and you can get it from here . # Firstly add koordinator charts repository if you haven't do this. $ helm repo add koordinator-sh https://koordinator-sh.github
