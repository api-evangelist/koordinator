We are happy to announce the release of Koordinator v0.6.0. Koordinator v0.6.0 brings complete Fine-grained CPU Orchestration, Resource Reservation mechanism, safely Pod Migration mechanism and Descheduling Framework. Install or Upgrade to Koordinator v0.6.0 ​ Install with helms ​ Koordinator can be simply installed by helm v3.5+, which is a simple command-line tool, and you can get it from here . # Firstly add koordinator charts repository if you haven't do this. $ helm repo add koordinator-sh https://koordinator-sh.github.io/charts/ # [Optional] $ helm repo update # Install the latest versio
